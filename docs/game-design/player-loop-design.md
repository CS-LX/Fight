# 竞技场经济循环 — 策划案 v1.0

## 1. 核心概念

**世界观**：玩家是一名「竞技师」，在竞技场中通过训练角色、参与对战、赞助比赛来积累财富和声望。

**核心循环**：
```
赚取货币（赞助/对战）→ 消耗货币（部署角色/创建角色）→ 角色变强 → 赚更多货币
```

**两种对战形态**：
| 模式 | 玩家角色 | 对战双方 | 本质 |
|------|---------|---------|------|
| AI对战 / 排位 | 指挥官（部署一方） | 玩家部署红/蓝方 vs AI部署另一方 | 人 vs 机 |
| 赞助观战 | 赞助商（旁观押注） | AI部署红方 vs AI部署蓝方 | 机 vs 机 |

> 关键区分：「对战」中玩家是参赛者，亲手选择并放置己方角色；「观战」中双方都是 AI 玩家在操作，人类玩家只负责选边押注。

**三种玩家角色**：
| 类型 | 行为 | 对应玩法 |
|------|------|---------|
| 观众型 | 看比赛、押注 | 赞助系统 |
| 竞技型 | 亲自上场打 | PvP/PvE 对战 |
| 创作型 | 设计自己的角色 | UGC 工坊 |

## 3. 赞助系统（观战押注）

> **命名**：避免"赌博/赌钱"等敏感词，统一用「赞助」。玩家是"赞助商"，为看好的队伍"投资"。

### 3.1 流程

```
1. 玩家进入「竞技大厅」
2. 大厅中有多场 AI vs AI 或 玩家 vs 玩家 的比赛正在进行/即将开始
3. 玩家选择一场比赛 → 进入观战界面
4. 开战前有 15 秒「赞助窗口」，玩家选择赞助哪一方
5. 比赛进行，玩家实时观战
6. 比赛结束 → 结算：
   - 赞助了胜方：本金 × 赔率 = 收益
   - 赞助了败方：本金损失
```

### 3.2 赔率机制

赔率根据双方实力自动计算：

```
赔率 = 对手总战力 / 己方总战力
```

| 场景 | 赔率 | 意义 |
|------|------|------|
| 强队 vs 弱队（押强队） | 1.2x | 低风险低回报 |
| 势均力敌 | 1.8x | 中等 |
| 强队 vs 弱队（押弱队） | 3.0x | 高风险高回报（爆冷） |

**赞助上限**：单场最多押入当前金币的 50%，防止一把梭哈归零。

### 3.3 赞助池与对战分成

所有赞助金额汇入「赞助池」：
- 败方赞助商的金币 → 全部进入赞助池
- 赞助池分配：
  - **70%** → 胜方赞助商按比例瓜分
  - **20%** → 对战双方选手奖金（胜者 15%，败者 5%）
  - **10%** → 系统回收（经济调控）

## 4. 对战系统

### 4.1 模式

| 模式 | 对手 | 条件 | 奖励 |
|------|------|------|------|
| AI 对战 | 系统 AI 队伍 | 随时可打 | 基础奖励 ×0.8 |
| 排位对战 | 真人玩家 | 匹配系统 | 基础奖励 ×1.5 + 赞助池分成 |
| 挑战赛 | 指定玩家 | 双方同意 | 自定义赌注 |

### 4.2 对战流程

```
1. 玩家选择模式
2. 进入「备战阶段」（15-30秒）
   - 从自己拥有的角色中选择上场阵容
   - 每个角色有部署成本（按稀有度）
   - 总部署预算有上限（防止土豪碾压）
3. 双方确认 → 赞助窗口开放（观众可押注）
4. 自动战斗开始
5. 结算
```

### 4.3 部署成本

| 角色稀有度 | 部署成本 | 说明 |
|-----------|---------|------|
| 普通 (C) | 20 金币 | 基础角色 |
| 精良 (B) | 50 金币 | |
| 稀有 (A) | 100 金币 | |
| UGC 自创 | 80 金币 | 固定成本 |

**部署预算上限**：每场比赛总部署不超过 300 金币（保证公平）。

### 4.4 奖励结算

```
胜者收入 = 基础奖励(80) + 赞助池分成(15%) + 连胜加成
败者收入 = 安慰奖(20) + 赞助池分成(5%)
双方支出 = 角色部署成本
```

**防破产机制**：
- 金币 < 50 时触发「救济」，免费获得 100 金币（每日限一次）
- AI 对战模式永远可用且部署成本减半

## 5. 人机系统（AI 填充）

### 5.1 触发条件

| 场景 | AI 行为 |
|------|---------|
| 竞技大厅比赛不足 | 系统自动生成 AI vs AI 比赛供赞助 |
| 排位匹配超时(>15秒) | 匹配 AI 对手 |
| 赞助人数不足 | AI "观众" 自动小额押注充实赞助池 |

### 5.2 AI 玩家特征

- 有拟人名字和头像
- 阵容从角色池随机组合
- 实力根据当前场次的平均水平浮动
- 不标注"AI"（但可在设置中开启标注）

## 6. UGC 角色创建

### 6.1 流程

```
1. 玩家进入「工坊」
2. 支付 2000 创造晶 开始创建
3. 配置角色：
   - 外观：上传图片 / AI 生成 / 选预设
   - 属性：在总点数内分配 HP/ATK/SPD/Range
   - 行为树：可视化编辑 AI 行为
4. 测试：在沙盒中测试角色表现
5. 发布：角色进入个人收藏，可用于对战
```

### 6.2 平衡限制

- **总点数制**：所有属性共享固定点数池（如 100 点），不能全加攻击
- **行为树复杂度上限**：最多 N 个节点，防止超级 AI
- **对战时有稀有度对标**：UGC 角色统一按 B 级计算部署成本

### 6.3 UGC 社交

- 可以把自创角色「上架」给其他玩家使用
- 被使用次数多的角色给创作者分成（被动收入）
- 赛季评选「最佳 UGC 角色」给予额外奖励

## 9. 风险与对策

| 风险 | 对策 |
|------|------|
| 押注被认定为赌博 | 用"赞助"包装；设置每日押注上限；虚拟货币不可提现 |
| 经济通胀（金币太多） | 系统回收 10%；部署成本随等级增加；UGC 消耗大量货币 |
| 经济通缩（玩家没钱） | 每日保底；AI 对战低成本；救济机制 |
| 土豪碾压 | 部署预算上限；属性点数制；匹配按战力分段 |
| 玩家太少 | AI 填充所有环节；AI 观众充实赞助池 |
| UGC 角色过强 | 总点数制；统一稀有度；定期平衡审核 |
