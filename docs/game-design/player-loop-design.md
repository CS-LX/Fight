# 竞技场经济循环 — 策划案 v1.0

## 1. 核心概念

**世界观**：玩家是一名「竞技师」，在竞技场中通过训练角色、参与对战、赞助比赛来积累财富和声望。

**核心循环**：
```
赚取货币（赞助/对战）→ 消耗货币（部署角色/创建角色）→ 角色变强 → 赚更多货币
```

**两种对战形态**：
| 模式 | 玩家角色 | 对战双方 | 本质 |
|------|---------|---------|------|
| AI对战 / 排位 | 指挥官（部署一方） | 玩家部署红/蓝方 vs AI部署另一方 | 人 vs 机 |
| 赞助观战 | 赞助商（旁观押注） | AI部署红方 vs AI部署蓝方 | 机 vs 机 |

> 关键区分：「对战」中玩家是参赛者，亲手选择并放置己方角色；「观战」中双方都是 AI 玩家在操作，人类玩家只负责选边押注。

**三种玩家角色**：
| 类型 | 行为 | 对应玩法 |
|------|------|---------|
| 观众型 | 看比赛、押注 | 赞助系统 |
| 竞技型 | 亲自上场打 | PvP/PvE 对战 |
| 创作型 | 设计自己的角色 | UGC 工坊 |

| 货币 | 名称 | 获取 | 用途 |
|------|------|------|------|

| 高级货币 | 创造晶 | 对战连胜、成就、赛季奖励 | UGC 角色创建、稀有角色解锁 |

### 2.2 经济参数（需要调优）

| 参数 | 初始值 | 说明 |
|------|--------|------|

| 每日登录奖励 | 50 | 保底收入，防止破产 |
| 单场部署成本 | 30-100 | 根据角色稀有度 |
| 对战胜利基础奖励 | 80 | 固定收入，不依赖观众 |
| 赞助池分成比例 | 胜者得 70% | 对战选手从赞助池中抽成 |
| UGC 角色创建费 | 2000 创造晶 | 高门槛，长期目标 |

## 3. 赞助系统（观战押注）

> **命名**：避免"赌博/赌钱"等敏感词，统一用「赞助」。玩家是"赞助商"，为看好的队伍"投资"。

### 3.1 流程

```
1. 玩家进入「竞技大厅」
2. 大厅中有多场 AI vs AI 或 玩家 vs 玩家 的比赛正在进行/即将开始
3. 玩家选择一场比赛 → 进入观战界面
4. 开战前有 15 秒「赞助窗口」，玩家选择赞助哪一方
5. 比赛进行，玩家实时观战
6. 比赛结束 → 结算：
   - 赞助了胜方：本金 × 赔率 = 收益
   - 赞助了败方：本金损失
```

### 3.2 赔率机制

赔率根据双方实力自动计算：

```
赔率 = 对手总战力 / 己方总战力
```

| 场景 | 赔率 | 意义 |
|------|------|------|
| 强队 vs 弱队（押强队） | 1.2x | 低风险低回报 |
| 势均力敌 | 1.8x | 中等 |
| 强队 vs 弱队（押弱队） | 3.0x | 高风险高回报（爆冷） |

**赞助上限**：单场最多押入当前金币的 50%，防止一把梭哈归零。

### 3.3 赞助池与对战分成

所有赞助金额汇入「赞助池」：
- 败方赞助商的金币 → 全部进入赞助池
- 赞助池分配：
  - **70%** → 胜方赞助商按比例瓜分
  - **20%** → 对战双方选手奖金（胜者 15%，败者 5%）
  - **10%** → 系统回收（经济调控）

## 4. 对战系统

### 4.1 模式

| 模式 | 对手 | 条件 | 奖励 |
|------|------|------|------|
| AI 对战 | 系统 AI 队伍 | 随时可打 | 基础奖励 ×0.8 |
| 排位对战 | 真人玩家 | 匹配系统 | 基础奖励 ×1.5 + 赞助池分成 |
| 好友对战 | 在线好友 | 房间码邀请 | 胜者 ×1.5 + 败者安慰奖 |

### 4.2 对战流程

```
1. 玩家选择模式
2. 进入「备战阶段」（15-30秒）
   - 从自己拥有的角色中选择上场阵容
   - 每个角色有部署成本（按稀有度）
   - 总部署预算有上限（防止土豪碾压）
3. 双方确认 → 赞助窗口开放（观众可押注）
4. 自动战斗开始
5. 结算
```

### 4.3 部署成本

| 角色稀有度 | 部署成本 | 说明 |
|-----------|---------|------|
| 普通 (C) | 20 金币 | 基础角色 |
| 精良 (B) | 50 金币 | |
| 稀有 (A) | 100 金币 | |
| UGC 自创 | 80 金币 | 固定成本 |

**部署预算上限**：每场比赛总部署不超过 300 金币（保证公平）。

### 4.4 奖励结算

```
胜者收入 = 基础奖励(80) + 赞助池分成(15%) + 连胜加成
败者收入 = 安慰奖(20) + 赞助池分成(5%)
双方支出 = 角色部署成本
```

**防破产机制**：
- 金币 < 50 时触发「救济」，免费获得 100 金币（每日限一次）
- AI 对战模式永远可用且部署成本减半

## 5. 人机系统（AI 填充）

### 5.1 触发条件

| 场景 | AI 行为 |
|------|---------|
| 竞技大厅比赛不足 | 系统自动生成 AI vs AI 比赛供赞助 |
| 排位匹配超时(>15秒) | 匹配 AI 对手 |
| 赞助人数不足 | AI "观众" 自动小额押注充实赞助池 |

### 5.2 AI 玩家特征

- 有拟人名字和头像
- 阵容从角色池随机组合
- 实力根据当前场次的平均水平浮动
- 不标注"AI"（但可在设置中开启标注）

## 6. UGC 角色创建

### 6.1 流程

```
1. 玩家进入「工坊」
2. 支付 2000 创造晶 开始创建
3. 配置角色：
   - 外观：上传图片 / AI 生成 / 选预设
   - 属性：在总点数内分配 HP/ATK/SPD/Range
   - 行为树：可视化编辑 AI 行为
4. 测试：在沙盒中测试角色表现
5. 发布：角色进入个人收藏，可用于对战
```

### 6.2 平衡限制

- **总点数制**：所有属性共享固定点数池（如 100 点），不能全加攻击
- **行为树复杂度上限**：最多 N 个节点，防止超级 AI
- **对战时有稀有度对标**：UGC 角色统一按 B 级计算部署成本

### 6.3 UGC 分享（轻量方案）

- 生成「角色分享码」，其他玩家输入即可导入到自己的角色库
- 社区「今日推荐」每日展示随机角色供体验
- 点赞/收藏机制（轻互动，无复杂交易和分成系统）

> ⚠️ 设计原则：不做角色市场/交易所/分成结算等重运营系统。UGC 的乐趣在于「创造+分享」本身，而非经济回报。

## 7. 排行榜

> **设计原则**：永久累计，不做赛季重置。玩家随时能看到自己的进步，不制造焦虑。

### 7.1 榜单设计

| 项目 | 方案 |
|------|------|
| 榜单类型 | **累计胜场榜**（单榜，简洁直观） |
| 重置策略 | 不重置，永久累计 |
| 数据源 | `cloudScore` 排行榜 API（零后端开发） |
| 展示位置 | 大厅右上角按钮，点击打开浮层面板 |
| 排行内容 | 排名 / 玩家名 / 累计胜场数 |
| 自己排名 | 面板底部固定显示「我的排名：第 N 名 / XX 胜」 |
| 刷新频率 | 进入大厅时拉取一次 |

### 7.2 排行榜与好友对战联动

- 排行榜入口同时提供「挑战」按钮（见 §8 好友对战）
- 胜场来源：AI 对战、排位对战、好友对战均计入

## 8. 好友对战（房间制）

> **设计原则**：不做好友列表/匹配队列，用房间码直接邀请。一局 2-3 分钟，随开随打。

### 8.1 流程

```
玩家A：大厅 → 好友对战 → 创建房间 → 显示房间码 "A3X7"（可分享）
玩家B：大厅 → 好友对战 → 输入房间码 → 加入房间

双方就绪 → 同时进入部署（30 秒倒计时，互相不可见）
  → 部署结束 → 自动开战（双方实时观看同一场战斗）
  → 结算 → 留在房间（可再来一局）或退出
```

### 8.2 规则

| 项目 | 设计 |
|------|------|
| 入口 | 大厅「好友对战」按钮 |
| 房间码 | 4 位字母数字，创建后 5 分钟有效 |
| 部署阶段 | 双方同时 30 秒，互看不到对方阵容 |
| 部署成本 | 正常扣费（和 AI 对战一致） |
| 部署预算 | 同全局上限 300 金币 |
| 战斗观看 | 双方实时同步观看 |
| 结算-胜者 | +1 胜场（计入排行榜）+ 金币奖励 ×1.5 |
| 结算-败者 | +安慰奖 20 金币（不计胜场） |
| 断线处理 | 掉线方由 AI 接管当前阵容，对方正常打完 |
| 再来一局 | 结算后双方留在房间，可直接再开 |
| 无好友系统 | 不做好友列表/添加好友，房间码通过微信/QQ 分享 |

### 8.3 技术方案

| 层面 | 方案 |
|------|------|
| 网络架构 | 使用引擎 `multiplayer` 房间制（已有基础设施） |
| 房间管理 | 服务端生成码 + 匹配加入 |
| 部署同步 | 双方各自提交部署阵容 JSON → 服务端汇总 → 下发双方 |
| 战斗同步 | 服务端权威：统一随机种子 + 逐帧逻辑，客户端纯渲染 |
| 断线重连 | 5 秒内重连恢复；超时由 AI 接管 |

## 9. 留存机制（轻量版，非赛季）

> **设计原则**：作为休闲小游戏，用每日任务和成就系统替代重度赛季模式。不做积分重置、段位降级等制造焦虑的机制。

| 机制 | 内容 | 奖励 |
|------|------|------|
| 每日任务 | 打1局 / 观战1场 / 创建或编辑1角色 | 50 金币 + 20 创造晶 |
| 成就系统 | 累计胜场/创建角色数/观战场数里程碑 | 一次性创造晶奖励 |
| 登录奖励 | 每日首次进入 | 50 金币 |
| 广告激励 | 主动观看广告 | 100 创造晶 或 复活 200 金币 |

> ❌ 不做的事：赛季重置、月度结算、段位衰减、限时活动运营

## 11. 风险与对策

| 风险 | 对策 |
|------|------|
| 押注被认定为赌博 | 用"赞助"包装；设置每日押注上限；虚拟货币不可提现 |
| 经济通胀（金币太多） | 系统回收 10%；UGC 消耗大量创造晶 |
| 经济通缩（玩家没钱） | 每日保底；AI 对战低成本；救济机制；广告激励 |
| UGC 角色过强 | 总点数制；统一稀有度 B 级 |
| 内容单调 | 丰富预制角色数量；地形变化；天气随机事件 |
| 留存不足 | 每日任务 + 成就系统（轻量激励，不制造焦虑） |

## 12. 总结

**产品定位**：TapTap 轻量休闲小游戏，3 分钟一局的 AI 自走棋 + UGC 角色创作 + 好友对战。


**一句话总结**：看比赛赚小钱，打比赛赚大钱，约好友争高下，花大钱造角色。四条路径互相喂养，排行榜提供长期目标，AI 填充保证随时可玩。

**不做的事**：赛季系统、段位衰减、角色市场/交易所、限时活动、好友列表系统。保持小而美。
