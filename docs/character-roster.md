## 角色定位分析

### 已覆盖的战术生态位

| 生态位 | 角色 | 说明 |
|--------|------|------|
| 高爆发近战 DPS | 维维美 | 低血高攻快刀，典型刺客 |
| 前排肉盾 | 狼泡泡 | 高血低速，驻守型坦克 |
| 远程风筝 | 小咲 | 远距离射击+近身自动撤退，ADC 位 |
| 低成本数量压制 | 源石虫 | 极低费用(推测)，蜂群集火战术 |
| 中庸辅助战士 | Doro | 血量适中、巡逻支援，半肉半输出 |

### 当前阵容特征

- **近战 3 / 远程 1 / 炮灰 1**
- **缺乏**：治疗/增益、AOE 输出、冲锋突进、超远程狙击、召唤/分裂
- **AI 类型分布**：aggressive / defensive / balanced / swarm / support 各一

## 缺失的战术位（建议补充）

### 1. 治疗/增益型（Healer / Buffer）

**战术缺口**：当前没有角色能恢复队友血量或提供增益 buff，长线对耗没有续航。

| 属性 | 建议范围 |
|------|---------|
| HP | 90~110 |
| 攻击 | 3~5（微弱自卫） |
| 技能 | 范围治疗 / 单体回复 |
| 射程 | 2.0~3.0（中距离） |
| 移速 | 2.0~2.5 |
| AI | 跟随最低血量友军，保持安全距离 |

**设计方向**：小精灵/牧师/奶妈，站后排给队友回血。

---

### 2. AOE 法师（Area Mage）

**战术缺口**：面对源石虫类蜂群时缺乏有效清场手段，需要范围伤害角色。

| 属性 | 建议范围 |
|------|---------|
| HP | 70~90 |
| 攻击 | 5（单次低，但范围命中多目标总伤高） |
| 技能 | 落点 AOE / 扇形攻击 |
| 射程 | 2.5~4.0 |
| 攻速 | 1.5~2.0（慢频率高价值） |
| 移速 | 1.8~2.2 |
| AI | 优先瞄准敌群密集点 |

**设计方向**：火球法师/元素术士，每次攻击对一个区域造成伤害。

---

### 3. 冲锋突进型（Charger）

**战术缺口**：缺少能快速切入后排击杀高价值目标（如射手/治疗）的突进角色。

| 属性 | 建议范围 |
|------|---------|
| HP | 100~130 |
| 攻击 | 12~14 |
| 技能 | 冲锋突进（短暂加速+首次攻击暴击） |
| 射程 | 1.0（近战） |
| 移速 | 2.5 常态 / 5.0 冲锋 |
| AI | 忽略前排，直冲最远/最弱后排目标 |

**设计方向**：骑士/突击兵，直接穿过前排冲向后排。

---

### 4. 超远程狙击（Sniper）

**战术缺口**：小咲射程 3.5 已经是最远，但没有"极限射程+高单发伤害"的狙击定位。

| 属性 | 建议范围 |
|------|---------|
| HP | 60~80 |
| 攻击 | 20~25（高单发） |
| 射程 | 5.0~6.0 |
| 攻速 | 2.0~2.5（极慢） |
| 移速 | 1.5~1.8（笨重） |
| AI | 不移动/极少移动，锁定最高威胁目标 |

**设计方向**：架在后排的炮台，一炮伤害极高但射速很慢。

---

### 5. 召唤/分裂型（Summoner）

**战术缺口**：当前只有"一次性部署"的数量优势（源石虫），缺少战场中动态生成新单位的角色。

| 属性 | 建议范围 |
|------|---------|
| HP | 90~110（本体） |
| 攻击 | 5（本体弱，召唤物输出） |
| 技能 | 每 N 秒召唤 1~2 个小单位 |
| 召唤物 | HP 30, ATK 4, 持续 5~8 秒后消失 |
| 移速 | 2.0 |
| AI | 保持中距离，持续召唤消耗对方 |

**设计方向**：死灵法师/虫母，持续产生低费小兵形成数量压力。

---

## 优先级建议

| 优先级 | 角色类型 | 理由 |
|--------|---------|------|
| P0 (最高) | 治疗/增益型 | 补全最核心的战术缺口，当前零续航 |
| P0 | AOE 法师 | 对抗蜂群的唯一解，且玩法丰富 |
| P1 | 冲锋突进型 | 增加战场动态性，打破前排僵持 |
| P1 | 超远程狙击 | 与冲锋型形成克制关系 |
| P2 | 召唤/分裂型 | 实现复杂度高，但玩法独特 |
